# 0.6.3 release record

0.6.3 corrects the MySQL adapter. A fresh install of the 0.6.2 `mysql` extra
resolves PyMySQL 1.2.3, under which every MySQL effect claim fails. 0.6.3 also
makes the MySQL stores' text handling independent of the pool's connection
charset. It adds no connector, action group, lifecycle state, or database
migration.

## Migration from 0.6.2

1. Pin the corrective patch:

   ```bash
   uv add "threvo-actions==0.6.3"
   ```

   A host that installs the `mysql` extra now resolves `PyMySQL>=1.2.3,<2`.

2. The MySQL stores send and read text as hex-encoded UTF-8, so stored and
   returned text no longer depends on the pool's charset. `utf8mb4` remains the
   documented pool configuration.
3. Text that is not valid UTF-8 raises `MySQLAdapterLimitError` before any
   statement runs. A proposal carrying such text fails before a connection
   opens. Hosts that already catch adapter limits at their boundary need no
   other change.
4. MySQL lookups match tenant and proposal references exactly, as the SQLite
   and PostgreSQL stores do. A reference with trailing spaces no longer finds
   the unpadded proposal or effect claim.

## Compatibility

Action identities, request and snapshot models, migrations, grants, receipts,
and canonicalization remain unchanged. Existing MySQL rows need no migration:
the schema is unchanged, and the stores read every stored text value back as
UTF-8. The SQLite, PostgreSQL, and in-memory stores are unchanged. Published
requirements change only in the `mysql` extra (`PyMySQL>=1.2.3,<2`) and the
`docs` extra (`mkdocstrings[python]>=1.0.7,<2`).

## Qualification

The MySQL suites run on MySQL 8.0 and 8.4 with PyMySQL 1.2.3 and aiomysql
0.3.2. They cover non-`utf8mb4` pools, exact reference matching, the encoding
of every text parameter a store sends, and rows that disagree with their
proposal. Publication requires the normal complete test, type, lint, migration,
installed-wheel, signed-tag, artifact-identity, TestPyPI, and PyPI promotion
checks. Threvo remains the maintainer-owned pilot and does not establish
independent adoption or production qualification.
